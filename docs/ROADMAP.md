# AI Agent Learning Roadmap

## Ultimate Goal

Learn AI systems through hands-on development and build a
hybrid local + cloud AI coding assistant.

Use a local Ubuntu/NVIDIA server for experimentation and
local inference, with cloud models where appropriate.

## Learning Phases

- [x] Infrastructure: Ubuntu, Docker, NVIDIA GPU, Ollama
- [x] Python-to-local-LLM API integration
- [ ] LLM fundamentals: tokens, context, transformers, MoE
- [ ] Prompt engineering and structured outputs
- [ ] Model APIs and application integration
- [ ] Embeddings, vector databases, and RAG
- [ ] AI agents: tools, planning, execution, memory
- [ ] Agent frameworks and orchestration
- [ ] MCP and external tool integration
- [ ] Multi-agent systems and A2A communication
- [ ] Evaluation, observability, and performance
- [ ] Fine-tuning and model adaptation
- [ ] Capstone: hybrid local + cloud coding assistant

## Learning Method

For every topic:

1. Understand the concept.
2. Implement a focused hands-on experiment.
3. Analyze the observations.
4. Document findings in the repository.
5. Commit the checkpoint before proceeding.

Prefer understanding underlying APIs and mechanisms before
introducing abstraction-heavy frameworks.

Skip general Python fundamentals; Python and OOP experience
is already established.
